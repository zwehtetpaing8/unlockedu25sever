  • Q2

3.2 Lines
➡️ Directed Values & Length
$$\langle PQ \rangle = \langle l,m,n \rangle = \langle x_2-x_1,\ y_2-y_1,\ z_2-z_1 \rangle$$ $$|PQ| = \sqrt{l^2 + m^2 + n^2}$$
📝 Equation of a Line
$$\text{Coordinate form: }(x,y,z) = (x_1+kl,\ y_1+km,\ z_1+kn)$$ $$\text{Symmetric form: }\frac{x-x_1}{l} = \frac{y-y_1}{m} = \frac{z-z_1}{n}$$
📝 Question Types — 3.2
  • Q1
    Find coordinates of point R on line PQ for given k
    Find ⟨PQ⟩ → write coordinate form → substitute k
  • Q2
    Check if point is on line PQ
    Write coordinate form → substitute point → solve k from each equation
    ✅ All k equal → on the line    ✗ k not equal → not on the line
3.3 Parallel, Skew & Perpendicular Lines
∥ Parallel Lines
$$\langle PQ \rangle = k\langle OA \rangle \iff PQ \parallel OA$$
One directed value is a scalar multiple of the other.
📐 Angle Between Two Lines
$$\cos\angle PAQ = \frac{l_1l_2 + m_1m_2 + n_1n_2}{\sqrt{l_1^2+m_1^2+n_1^2}\cdot\sqrt{l_2^2+m_2^2+n_2^2}}$$
⊥ Perpendicular Lines Condition
$$l_1l_2 + m_1m_2 + n_1n_2 = 0$$
Must also intersect to be truly perpendicular.
📝 Question Types — 3.3
  • Q1
    Find cos∠PAQ
    Find ⟨AP⟩ and ⟨AQ⟩ → substitute into angle formula
  • Q2
    Parallel / Skew / Intersect
    ① Check ⟨PQ⟩ = k⟨RS⟩ → yes: parallel
    ② Solve simultaneous equations → consistent: intersect (check ⊥)
    ③ Contradiction → skew
  • Q3
    Find line through point P, ⊥ to given line
    ① Directed values of required line = ⟨P − point on given line with k⟩
    ② Dot product = 0 → find k → get directed values
    ③ Write line equation → find intersection point
  • Q4
    Show two lines are perpendicular
    ① Show they intersect (find s and t)
    ② Show l₁l₂ + m₁m₂ + n₁n₂ = 0 ✓
3.4 Planes
💡 Key Rule: When a line is ⊥ to plane ax+by+cz=d, its directed values are ⟨a, b, c⟩ — the coefficients of the plane become the directed values of the perpendicular line.
📐 Q1 — Equation of Plane Through 3 Points A, B, C
  • 1
    Find ⟨AB⟩ = ⟨l₁,m₁,n₁⟩ and ⟨AC⟩ = ⟨l₂,m₂,n₂⟩
  • 2
    Find normal vector:
    a = m₁n₂ − m₂n₁  |  b = n₁l₂ − n₂l₁  |  c = l₁m₂ − l₂m₁
  • 3
    Find d = ax₁ + by₁ + cz₁ using any of the 3 points
  • 4
    Write equation of the plane:
$$\boxed{ax + by + cz = d}$$
📌 Q2 — Line Through Point ⊥ to Plane → Find Intersection
Directed values of ⊥ line = ⟨a, b, c⟩ from plane ax+by+cz=d
  • 1
    Write line: (x,y,z) = (x₁+ak, y₁+bk, z₁+ck)
  • 2
    Substitute into plane equation → find k
  • 3
    Substitute k back → find intersection point P
∥ Q3 — Plane Parallel to Given Plane Through a Point
Parallel planes share same ⟨a, b, c⟩ — only d changes
  • 1
    Keep same a, b, c from given plane
  • 2
    Find d = ax₁ + by₁ + cz₁ using the given point
  • 3
    Write equation of the plane:
$$\boxed{ax + by + cz = d}$$
3.5 Spheres
⭕ Equation of a Sphere
$$\boxed{(x-x_1)^2 + (y-y_1)^2 + (z-z_1)^2 = r^2}$$
Center: (x₁,y₁,z₁)  |  Radius: r
📌 Point vs Sphere
ConditionPosition
CP < rInside the sphere
CP = rOn the sphere
CP > rOutside the sphere
💡 Key Rule: When a line is ⊥ to a plane, its directed values become ⟨a, b, c⟩ of that plane. This applies to both tangent planes and touching planes in sphere problems.
📐 Q1 — Tangent Plane to Sphere at Point P
Line CP ⊥ tangent plane → ⟨CP⟩ = ⟨a,b,c⟩ of the tangent plane
  • 1
    Find ⟨CP⟩ = directed values from center C to point P on sphere → these become ⟨a,b,c⟩
  • 2
    Tangent plane form: ax+by+cz=d
  • 3
    Substitute point P → find d
  • 4
    Write equation of the tangent plane:
$$\boxed{ax + by + cz = d}$$
💡 Q2 — Sphere with Center C Touching a Plane
Line from C ⊥ to plane ax+by+cz=d has directed values ⟨a,b,c⟩
  • 1
    Write line through center C using ⟨a,b,c⟩ from the plane:
    (x,y,z) = (xc+ak, yc+bk, zc+ck)
  • 2
    Substitute into plane equation → find k → find touching point
  • 3
    Find r = distance from center to touching point
  • 4
    Write equation of the sphere:
$$\boxed{(x-x_c)^2 + (y-y_c)^2 + (z-z_c)^2 = r^2}$$
🔵 Q3 — Sphere on Diameter AB
  • 1
    Center = Midpoint of A and B
  • 2
    Find AB → Radius r = AB / 2
  • 3
    Write equation of the sphere:
$$\boxed{(x-x_1)^2 + (y-y_1)^2 + (z-z_1)^2 = r^2}$$
🌐 Q4 — Sphere Through 3 Points, Center on Plane / Axis
  • 1
    Let center = C(x₁,y₁,z₁) with constraint (e.g. on yz-plane → x₁=0)
  • 2
    Set up 3 equations: distance from C to each point = r
    → expand and set equal pairwise
  • 3
    Subtract equations to eliminate r² → solve system for x₁,y₁,z₁
  • 4
    Find r² by substituting center back → write equation of the sphere:
$$\boxed{(x-x_1)^2 + (y-y_1)^2 + (z-z_1)^2 = r^2}$$
